## 문제

청년 혜택은 정부24, 한국장학재단, 온통청년, 복지로 등 여러 곳에 흩어져 있어서, 자기 조건에 맞는 혜택을 찾으려면 사이트마다 공고를 따로 확인해야 한다.

## 접근

여러 기관의 혜택 공고를 매일 수집하고 지역, 생년월일, 학적, 소득구간, 취업상태를 담은 프로필에 맞춰 추천한다. 혜택마다 공식 신청처와 접수 방식, 서류 체크 목록을 안내하고, 서류는 기기 안의 AES-256 암호화 보관함에 두며 마감 전에 푸시 알림을 보낸다. 신청서를 대신 작성하거나 기관에 제출하지는 않는다.

AI 혜택 비서는 조건 확인이나 공고 원문 질문 같은 읽기 요청을 바로 처리한다. 알림 켜기나 저장, 신청 상태 기록처럼 상태를 바꾸는 행동은 확인 카드로 보여 주고, 사용자가 승인해야 서버가 실행한다. 자격 판정과 금액, 날짜, 서류는 모델이 아니라 서버 규칙이 정한다.

## 결과

팀은 2026년 9월 웹 앱과 API, 수집 워커를 오라클 클라우드에 배포했고, 10월에 Android 테스트 빌드를 만들었다. iOS 실기기 검증과 App Store 제출은 아직 끝나지 않았다.

## 내 역할

수집과 API, AI 혜택 비서의 대부분은 팀원이 만들었고, 내 커밋은 2026년 10월부터다. Android 테스트 빌드에서 보고된 화면 이동 문제를 고쳐 같은 화면이 누른 만큼 쌓이지 않게 했다. 로그인이 필요한 기능은 이유를 먼저 알리고, 로그인이 끝나면 원래 화면으로 돌아오게 했다. 조건 입력과 추천 흐름도 정리했다. 푸시 토큰을 등록하게 하고, 알림을 누르면 해당 혜택 화면이 열리게 했다.

상세 화면의 알림 버튼이 들어갈 때마다 꺼진 상태로 보이던 문제는 혜택별 알림 설정을 조회하는 API가 없어서 앱만으로는 고칠 수 없었다. Rust API에 혜택별 알림 상태 조회와 알림 읽음 처리, 읽지 않은 알림 수를 추가하고 사용자 id는 JWT에서만 받게 했으며, 앱은 새 API가 없는 서버에서도 이전처럼 동작하게 했다.

서류 작성 도우미의 입력 형식 검사와 임시 저장도 구현했지만 병합 때 보류되어 지금 서비스에는 없다. 11월부터는 AI 혜택 비서의 평가 도구가 사용자가 실제로 받는 확인 카드를 기준으로 재도록 고치는 작업을 하고 있고, 아직 병합되지 않았다. 구현에는 Claude Code를 활용했다.
